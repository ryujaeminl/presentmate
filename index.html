브라우저 전용 — 설치 불필요

Python·Streamlit·ffmpeg 없이 브라우저만으로 작동합니다. 마이크·카메라 권한만 허용하면 바로 사용할 수 있습니다. AI 피드백 및 전사 기능은 Gemini API 키가 필요하지만, 없어도 음향·구조·속도 분석은 모두 가능합니다.
API 키 저장: config/api_config.js 파일에 키를 입력하면 매번 입력할 필요가 없습니다.
